# 교재 공방 (tools/forge) 사용법

교재의 **그림·영상·소리**를 만들고, 듣고 보고 **승인**한 것만 교재(`web/assets/`)에 넣는 로컬 프로그램.
게임의 캐릭터 공방(`C:\game\tools\charforge`)을 본떠 만들었다. 만들 항목 목록은 `content/book.json`·`content/units/*.json`에서 **자동**으로 나온다 — 여기서 뭔가를 "새로 만들기" 할 필요가 없다.

## 1. 실행
1. 탐색기에서 `C:\phonics\tools\forge.cmd` 를 **더블클릭**. 검은 창이 뜨고 크롬이 `http://localhost:8766` 을 연다.
   - 처음 한 번 바탕화면에 **"교재 공방"** 바로가기가 생긴다. 다음부터는 그걸 더블클릭.
   - 검은 창을 닫으면 공방이 꺼진다. 작업 중엔 열어 둔다.
2. 처음 실행 때 게임 공방의 제미나이 API 키(`C:\game\art-src\charforge\secrets.json`)가 있으면 자동으로 복사해 온다 (`art-src/forge/secrets.json`, git 에는 안 올라감).
   - 없으면: 왼쪽 **진행·설정** → "제미나이 API" 칸에 키를 붙여 넣고 **설정 저장** → **그림 연결 시험** / **TTS 시험** 으로 확인.

## 2. 확장 프로그램 넣기 (플로우로 만들 때만. 제미나이 API 만 쓰면 건너뛴다)
1. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기.
2. **압축해제된 확장 프로그램을 로드합니다** → 폴더 `C:\phonics\tools\forge\extension` 선택.
3. 목록에 **"교재 공방 Flow Bridge"** 가 생긴다. 게임의 **"캐릭터 공방 Flow Bridge"** 가 있으면 **끈다** (둘 다 켜면 잡이 섞인다).
4. 크롬 오른쪽 위 퍼즐 아이콘 → "교재 공방 Flow Bridge" 클릭 → 서버 주소가 `http://localhost:8766` 인지 보고 **자동화 시작**.
5. 플로우(labs.google/fx 또는 flow.google.com)에 로그인해서 탭을 하나 열어 둔다. 공방 위쪽의 **확장: 연결됨**(초록 점)이 켜지면 된다.
- 확장의 제출 간격·속도 제한·결과 매칭은 게임 공방 확장과 **완전히 같다** (바꾸지 않았다). 다른 것은 이름과 기본 서버 주소(8766)뿐.

## 3. 화면
- **왼쪽**: 분류 — 캐릭터 / 글자나무 / 단어 그림 / 선 그림 / 캐스트 시트 / 스토리 장면 / 영상 / 소리 / 진행·설정. 숫자는 승인/전체. 맨 아래 **유닛 필터**(전체·0·1 …).
- **위쪽 막대**: 확장 연결 상태(초록/회색), **생성기**(플로우/제미나이 API — 기본값. 항목마다 따로 고를 수도 있다), **남은 것 전부 자동 생성**(지금 보는 분류·유닛), **승인된 것 전부 교재에 넣기**, **무인 모드**, 제미나이·TTS 사용량, 로그.
- **카드**(항목 하나): 썸네일(클릭하면 크게), 상태 배지(대기·자동 대기열·생성 중·검수·승인·실패), 단추 — 자동 생성 / 승인 / 승인 취소 / 버리기 / 다시 처리 / 교재에 넣기 / 생성기, 프롬프트 보기·고치기(고치면 저장되고 content 를 다시 읽어도 유지), **그림 끌어다 넣기**(칸을 클릭한 뒤 Ctrl+V 도 됨 — 플로우에서 손으로 만든 그림을 넣을 때).

## 4. 흐름 (이 순서로)
1. **캐릭터 기준 그림 4장** (`char_<이름>_ref`, 파란 테두리 카드): 캐릭터 분류에서 ref 카드의 **자동 생성** → 나오면 보고 **승인**. 마음에 안 들면 **버리기** → 다시 자동 생성(또는 프롬프트를 고치고).
   - 기준 그림이 승인돼야 그 캐릭터의 나머지 자세(기쁨·놀람·가리키기 … + 눈 감음·말하기)가 기준 그림을 **참조로 붙여** 만들어진다. 다른 자세는 "남은 것 전부 자동 생성"으로 한꺼번에.
   - 자세 그림이 다른 캐릭터로 나오면(참조 첨부 실패) 공방이 색·실루엣으로 알아채고 버린 뒤 다시 대기열에 넣는다. **캐릭터 동일성 검사** 단추로 손으로도 돌릴 수 있다.
   - **무인 모드**를 켜면 기준 그림을 나오는 대로 자동 승인한다 (자리 비울 때. 나중에 "자동 승인" 배지가 붙은 것을 꼭 확인).
2. **캐스트 시트**: 기준 그림 4장이 모두 승인되면 공방이 자동으로 4장을 흰 바탕에 나란히 합성해 **승인** 상태로 둔다 (생성하지 않는다). 기준 그림을 바꾸면 다시 합성된다.
3. **스토리 장면**: 캐스트 시트를 참조로 붙여 만든다 (캐스트 시트가 있어야 대기열에서 나간다). 4:3, 1600×1200 JPEG.
4. **영상**: **플로우로만** (제미나이 API 는 영상을 못 만든다). 승인된 장면 그림을 붙여 "이미지 → 동영상"으로 보낸다. 비율(4:3)·길이(8초)는 플로우의 **전역 설정**이라 배치 시작 전에 플로우 화면에서 한 번 맞춰 둔다. 결과 mp4 그대로.
5. **글자나무**: 첫 나무(tree_a)가 기준 → 승인 → 나머지 나무가 같은 양식으로. 나무 간판은 **빈 채로** 나오고 글자는 웹 교재가 덧씌운다.
6. **단어 그림 78장**: 참조 없음. 그냥 자동 생성. → **선 그림 78장**은 승인된 단어 그림을 참조로 붙여 만든다 (워크북 색칠용. 검은 선만 남기고 나머지 투명).
7. 보고 **승인** → **교재에 넣기** (카드마다, 또는 위쪽 "승인된 것 전부 교재에 넣기"). `web/assets/art/<id>.png|jpg`, `web/assets/video/<id>.mp4` 로 복사(덮어씀).

## 5. 소리 탭 (TTS)
- 항목도 content 에서 자동: 글자 이름 26(`name_a`) · 낱소리 26(`sound_a`) · 단어 78(`word_apple`) · 사이트워드 19(`sw_I`) · 스토리 대사(`u01_l1` …) · 지시문(`instr_listen_repeat`).
- 항목마다 **후보 여러 개**를 만들고 들어 본 뒤 하나를 **승인**한다. 후보 = 대본 변형 × 목소리.
  - **기본 후보 바로 만들기**: 기본 대본 × 기본 목소리(book.json 의 캐릭터 voice / narrator_voice).
  - **후보 만들기…**: 대본을 여러 줄 적고 목소리를 여러 개 고르면 조합마다 후보가 생긴다.
  - **후보 없는 것 전부 만들기**: 지금 보는 분류·유닛에서 후보가 없는 항목 전부 (비용이 든다).
- 대본 규칙 (2026-10-06 실험 결과):
  - 낱소리는 **"/IPA/"**(예 `/b/`, `/æ/`)가 가장 깨끗하다 — 덧붙는 모음이 없다. `b` 만 보내면 "buh", `a` 는 글자 이름 "ay". 늘일 수 있는 소리(m n s f v z l r)는 `mmm` 같은 늘인 철자도 좋다. 세 번째 후보는 **같은 글자 첫 단어 음성의 앞부분 잘라내기**(파열음 180ms, 그 외 350ms, 20ms 페이드아웃).
  - 글자 이름은 대문자 한 글자(`A`)만.
  - 단어·대사·지시문은 공방이 앞에 `Say slowly and clearly: ` 를 붙여 보낸다 (설정에서 바꿀 수 있다). **긴 지시문을 대본에 넣으면 지시문까지 읽으니 금지.**
- **자동 검사**: 후보가 생기면 `gemini-3.5-flash-lite` 에 보내 무엇을 말했는지 물어 후보 옆에 작게 적는다 (예: `들림: "b" /b/ · clean`). **빨간 글씨**는 대본과 다르거나 낱소리에 모음이 덧붙은 것. 비용은 거의 0.
- 후보를 **승인**하면 ffmpeg 가 앞뒤 무음 제거 → 음량 맞춤(-16 LUFS, 피크 -1.5dB) → mp3 로 `final.mp3` 를 만든다. **교재에 넣기** → `web/assets/audio/<id>.mp3`.
- **직접 녹음**: 카드의 "녹음 파일 넣기" 칸에 wav/mp3 를 끌어다 놓으면 후보가 된다 (안 되는 낱소리만 직접 녹음).

## 6. 폴더
```
tools/forge/            server.py(서버) plan.py(항목 목록) presets.py(상수) imgproc.py(그림 뒤처리) audio.py(TTS·ffmpeg) static/(화면) extension/(크롬 확장)
art-src/forge/          settings.json · secrets.json(git 제외)
  <분류>/<id>/          raw.png(원본, git 제외) · cut.png|jpg|mp4(완성) · item.json(상태·프롬프트)
  _trash/               버린 그림
audio-src/forge/<id>/   cand_<n>.wav(후보, git 제외) · final.mp3(승인) · item.json
web/assets/art/ audio/ video/   교재가 읽는 파일 (교재에 넣기)
```
분류: char(캐릭터) tree(글자나무) word(단어 그림) line(선 그림) cast(캐스트 시트) scene(스토리 장면) video(영상).

## 7. 비용 (추정)
- 제미나이 그림: `gemini-3.1-flash-image` 512px $0.045 · 1K $0.067 · 2K $0.101 / `gemini-3-pro-image` 1K $0.134 (한 장당). 기본 1K.
  - 1·0유닛 샘플(캐릭터 36 + 나무 3 + 단어 78 + 선 78 + 장면 6 = 201장) ≈ $13.5 (1K). 다시 뽑기 포함 2배로 잡는다.
- TTS: 요청 수·음성 토큰을 진행·설정 화면에 표시 ("apple" 1건 = 27토큰, 1.1초).
- 플로우(확장)는 구독 크레딧.
- 설정·사용량은 `art-src/forge/settings.json` 에 쌓인다.

## 8. 문제가 나면
- "확장: 연결 안 됨": 확장 팝업에서 **자동화 시작**을 눌렀나, 서버 주소가 8766 인가, 플로우 탭이 열려 있나.
- 참조가 필요한 항목이 대기열에서 안 나감: 카드에 "참조 … 승인 대기"가 보인다 → 그 참조(기준 그림·캐스트 시트·단어 그림)를 먼저 승인.
- 제미나이 오류는 진행·설정 화면의 "마지막 오류"와 로그에 나온다.
- content JSON 을 고친 뒤: 진행·설정 → **content 다시 읽기** (이미 있는 그림·상태는 그대로, 프롬프트만 새로).
