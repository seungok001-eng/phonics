점검 범위: 4권 52유닛의 내용(JSON), 웹 교재·수업 슬라이드 코드, 종이 PDF(학생책·워크북·스토리북·시험지·정답지), 선생님 자료(수업안·정답지·시험지 생성기·진도표·가정통신문·이야기 안내서), 홈페이지. 네 갈래로 나눠 보고 한데 모았다.

## 1. 바로 고쳐야 할 것 [심각]

### 1-1. 정답이 뻔하거나 둘인 문제
- **2~4권 "Read and circle" 216문항은 정답이 늘 첫 번째 그림.** 데이터 `check.read_circle[].pictures[0]` 이 정답이고 화면·인쇄(`pages.js rcRow`)가 순서를 섞지 않는다. 아이가 1번만 골라도 만점. 워크북 문장 고르기도 a·b·a·b 번갈이.
- **시험지 생성기(최종 시험 포함) 정답 위치가 한 장 안에서 반복.** 예: 1권 Final L1 A·B 1부 6문항 전부 c, 3권 Unit 1 시험 전부 c. `test.html shuffle()` 의 난수가 약하다.
- **정답이 둘인 문항:** 2권 3유닛 워크북 "The hen has a pen."(그림 pen·hen), 4권 1유닛 "The cap is a cape!"(cape·cap).
- **그림이 겹쳐 고를 수 없음:** quack 그림이 오리라서 duck 과 같이 나오는 문항(3권 10·11유닛, 1권 7·12유닛), 2권 mug/cup, 4권 house/mouse/roof·tooth/mouth.
- **그림과 단어가 안 맞음:** 4권 5유닛 흰 고양이 + c_t_(cute → 아이는 cat), 1권 zipper 그림이 조끼(vest 로 읽힘), 2권 "The cat can sit." 의 sit 그림이 개, 4권 hope(강아지와 과자통).

### 1-2. 수업안이 없거나 엉뚱함
- **0·5·11·12유닛(도입·복습·쇼) 수업안이 빈 화면** — 4권 합쳐 28차시. 가정통신문·플래시카드도 1~10유닛만. (`lesson-plan.html` 55~63행에서 오류)
- **3·4권 수업안에 2권 예문이 박혀 있음** ("The cat is on the mat."), 1권 수업안은 모든 유닛이 1유닛 예시("This is A", "A raccoon!")와 지운 기능(▶ movie, 아이가 칠판에 나와 누르기)을 말한다.

### 1-3. 잘못 가르치게 되는 설명
- **3권 이어 소리(bl·br·sn·st·-nd·-mp…)와 qu 를 "두 글자, 소리 하나"로 설명.** 이어 소리는 두 소리를 빠르게 잇는 것. 학생책 안내·슬라이드·수업안·가정통신문 모두. 유닛 목표 문구와도 모순.
- **4권 u_e 유닛이 /juː/(cube)와 /uː/(flute·tube·tune·dune)를 섞음.** 게다가 타일을 누르면 늘 "you" 소리라 flute 가 "fl-you-t". **hug→huge** 는 안 배운 soft g(/dʒ/)가 필요.

### 1-4. 종이책에서 할 수 없는 활동
- **스토리북 인쇄본: 글 띠가 그림 아래 37%를 가린다.** "Find the …!" 과제의 물건이 띠 밑에 숨는다(1권 tomato·lantern·Pip, 2권 net·log·rug·bug, 3권 ring …).
- **종이에 "눌러요" 안내가 그대로** — "단어를 눌러 가족 상자에 넣어요"(45번), "▶ 를 누르면…"(38번) 등. 숙제할 때 부모가 헷갈린다.
- **"Let's play!" 칸은 종이에서 할 일이 없는 그림 3장**(1·2·4권 SB 11쪽 등).
- **1권 워크북 "Finish the story."** 고를 단어가 인쇄에서 빠져 고를 것이 없다.
- **2~4권 12유닛 "Cross the pond"** 안내문에 정답 순서가 다 적혀 있다.
- **1권 확인 쪽 "Find and circle. Then write."** 에 정답 단어가 인쇄된다.

## 3. 선생님이 따로 설명해야 하는 것 [보통]

**파닉스 내용**
- 안 배운 이어 소리 tr·sl·gl·pl 이 4권 대표 단어(tree·train·slide·globe)와 3권 plant 에 나온다.
- 이미 배운 사이트워드를 "새 단어"로 다시 지정(2권 12개, 3권 this·here, 4권 see·like·go·look).
- 자주 쓰는데 안 가르친 이야기 단어: no(Oh no!), for, of, read, door, together, lantern, party, magic, castle.
- 유닛 소리와 어긋나는 사이트워드: 3권 th 유닛의 this·that(/ð/), wh 유닛의 who(/h/), 4권 oo 유닛의 look(/ʊ/). thumb 은 b 묵음.
- 빠진 글자 문항 14개가 c/k 칸이라 소리는 맞게 써도 틀린다. 4권 rose 의 s(/z/).
- 그림으로 고르기 어려운 동사·형용사(2권 hit·sit·hot·wet·fun …, 3권 thin·quick·flip, 4권 hide·cute·huge·tune·ripe)와 낯선 단어(den·peg·cot·tin·fig·shed·clam·quill·crib·vane·robe·mule·dune·jay·hay).
- 이중 자음(ll·ss·ff)과 끝 묶음(-nch·-mb·-sk·-lt)을 가르치지 않는데 빈칸으로 묻는 문항이 있다(sniff 의 ff, spill 의 ll).

**슬라이드·활동**
- 놀이판에 말이 도착하자마자 답을 읽어 준다(아이가 먼저 외칠 기회가 없다).
- 단어 사냥 슬라이드에서 같은 라운드가 두 번 나온다.
- 빙고: 1권 아이가 16단어를 옮겨 쓰는 데 10분, 슬라이드가 선생님 판 기준으로 BINGO 를 띄운다.
- 2~4권 복습 워크북 두 쪽에 같은 분류 문제가 나온다.
- 알파벳 쪽(0유닛)은 슬라이드가 따로 없어 A4 쪽이 작게 들어간다.

**시험·자료**
- 최종 시험은 사양대로(수준 1~3·A/B·듣기 없음·정답지·점수표·말하기) **있지만 찾기 어렵다** — `_Tests_Review.pdf` 49~75쪽에 섞여 있고 홈페이지에 "최종 평가"라는 말이 없다. 말하기 체크리스트 링크는 1권 고정.
- 2~4권 첫 글자 쓰기 문항이 가족 점수표에 잘못 들어간다(tent 의 t 를 -nt 칸에).
- 말하기 채점 기준(0/1/2점)이 없다.
- 진도표 "22차시·11주"가 실제(25차시·약 13주)와 다르고 최종 평가 차시가 없다.
- 홈페이지 PDF 목록 128개가 권 구분 없는 같은 이름.
- 선생님용 **발음 안내(우리말)** 와 **슬라이드 사용법** 이 없다 — IPA(/æ/ /θ/)만 있어 파닉스 훈련이 없는 선생님은 읽기 어렵다.
- 수업안·플래시카드·진도표·가정통신문은 PDF 가 없다.

**종이 인쇄**
- 4권 마법 e 빈칸 표기가 들쭉날쭉(cape 는 e 도 빈칸, gate 는 e 가 회색).
- 선 잇기에 점(●)이 없고, 4선 쓰기 칸이 7~9세에게 좁다(가운데 4~5mm).
- 흑백 복사하면 묵음 e·가족 색·"빨간 글자가 모음"이 사라진다. 워크북 크림 바탕은 회색이 된다.
- 빈 반쪽이 많다(1·4권 0유닛, 4권 1·6·12유닛 등). 유닛 PDF 가 홀수 쪽이라 양면 인쇄가 어긋난다.
- 1권 그림 몇 개가 애매하다: nose, six(딸기), vet(부엉이), up(화살표), uncle(토끼).

**문서**
- `docs/01-concept.md` 가 옛 설정(Mina·Jun·Pomi·Digby, 11유닛)이다. `web/pdf/press/` 에 옛 PomiPhonics PDF 29개가 남아 있다.

## 4. 잘 되어 있는 것
- 수업 슬라이드는 원칙대로 **아이가 화면을 만질 필요가 없다**(번호를 외치고 선생님이 누른다).
- 음성 파일 누락 0개, 숙제가 그날 배운 것과 맞다, 정답이 보기 밖에 있는 문항이 없다.
- 2~4권 수업 구조가 같아 선생님이 바로 알아본다. 복습 범위가 빠짐없다. 1→4권 난이도 흐름에 무리가 없다.
- 이야기 자료(줄거리·칸 설명·번역·질문)가 4권 모두 있고 서로 맞다. 캐릭터 그림이 일관된다.
- 최종 시험의 내용이 권마다 맞다(2권 가족, 3권 짝꿍, 4권 마법 e·모음 짝). A/B 형이 실제로 다르다.

1. 정답 위치 섞기(학생책 Read and circle + 시험지 생성기), 정답 둘·그림 겹침 문항, 그림-단어 불일치.

4. 종이 인쇄: "눌러요" → 종이용 문구, 스토리북 글 띠, Let's play·Finish the story·Cross the pond·정답 인쇄.

7. 단어 바꾸기(낯선 단어·동사)와 그림 다시 그리기는 한꺼번에(탑뷰).

## 고친 결과 (2026-10-14, 사용자: "니가 알아서 다 고쳐줘")
세 갈래로 나눠 고쳤다(웹 교재 코드 · 선생님 자료 · 내용 데이터). 자세한 메모는 `docs/14-review-notes.md`.

**1. 정답·그림**
- 2~4권 Read and circle·워크북 문장 고르기: 정답 자리를 고르게 섞음(권마다 1·2·3번째 24/24/24). 화면·슬라이드·종이·정답지가 같은 순서.
- 시험지 생성기: 해시 난수(mulberry32) + 부분마다 정답 자리 고르게. 첫소리·끝소리 문항은 점수표의 따로 칸.
- 정답 둘·그림 겹침 정리(hen/pen → net/hen, cap/cape → cape/cake, quack 과 duck 떼기, mug/cup, house/roof, tooth/mouth), cute → cube, hope → rope, "The dog can sit."
- 그림 다시 그림(탑뷰): zipper·nose·six·vet·up·hot·mat·whip(휘핑크림) + 선 그림.
- 그림 고르기 문항의 동사·형용사를 같은 가족 명사로 바꿈. 같은 가족에 명사가 없는 red·fed·beg·dip·rip·flip·quick 은 그림이 분명해(빨간 물감·밥 먹는 강아지·조르는 강아지·소스·찢어진 종이·뒤집히는 팬케이크·달리는 치타) "단어를 읽고 그림 고르기"에는 남겨 둠.
- 동사·형용사는 book.json `words[w].abstract: true` 로 표시(2권 20개·3권 9개·4권 13개) — **그림만 보고 쓰는 문항**(시험지 수준 3 "Look and write the word", 복습 워크북 그림 보고 쓰기의 기본 목록)에서는 뺀다. 워크북 Look and write 는 흐린 글자를 따라 쓰는 활동이라 그대로.

**2. 파닉스 내용**
- 3권 이어 소리(bl·st·-nd…)와 qu: "두 소리를 빠르게 이어요"로 — 학생책·슬라이드·수업안·가정통신문 모두.
- 4권 u_e: 두 소리(cube /juː/, flute /uː/)로 가르침 — 타일·합치기 소리가 단어 소리를 따른다(flute·tube·tune·dune 은 oo 소리). hug→huge 는 빼고 짝은 다시 4쌍: i_e slid→slide, o_e glob→globe(있던 그림), u_e plum→plume(새 그림·소리, huge 자리를 plume 으로).
- 빈칸: c/k 칸 14개 → 모음·가족 칸, rose 는 o_e, 3·4권 check.write 는 4개 중 3개 이상 가족 칸.
- 사이트워드: 2권 no·for 추가, 앞 권에서 배운 말은 "복습" 꼬리표. th·who·oo·u_e·tr/sl/gl/pl 은 선생님 참고(수업안).
- 어색한 문장 고침 + 새 사이트워드가 문장 쪽에 나오게(녹음 15개 새로).
- 우리말 글의 발음 기호 191곳 → 글자(a·b·c, c-a-t).

**3. 수업안·시간**
- 수업안: 모든 유닛(0·5·11·12 포함)을 실제 쪽 목록에서 만든다 — 쪽마다 선생님 말·아이들 답·시간, 50분을 넘거나 40분 미만이면 대안 제시. 그 유닛 예문 사용, 지운 기능(영상·동작·칠판 누르기) 삭제. `?u=all` 은 권 전체.
- 쪽 옮김: 3권 9유닛 read_play → 2차시, 복습 5·11유닛 빙고 → 2차시, 12유닛 1차시에 빙고 추가, 2~4권 0유닛에 지난 권 단어 복습 쪽.
- 수업 화면: 차시 끝마다 "Homework · Workbook p.x–y" 장, 0유닛 알파벳 슬라이드, 선생님 화면 기본 "교재만".
- 놀이판(도착하면 불만 — 선생님이 눌러 확인), 단어 사냥(라운드 자동 넘김 없음), 빙고(부른 단어만 표시).
- 남은 시간 경고(수업안이 대안 제시): 3권 9유닛 2차시 58분·6~8유닛 1차시 51~55분·4권 1유닛 1차시 51분, 복습 유닛 1차시 25~36분.
