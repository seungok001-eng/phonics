# 교재 디자인 규칙 — "AI가 만든 것 같지 않게"

작성 2026-11-03. 사용자가 첨부한 시판 파닉스 교재 8쪽(알파벳 유닛 3쪽·장모음 유닛 5쪽)과 우리 1권 유닛 1(학생책 8~15쪽)을 나란히 놓고 뽑은 차이와, 앞으로 전면 재설계할 때 지킬 규칙이다. 첨부 교재는 **구도·여백·지시 체계를 배우는 기준**일 뿐이고, 그림·캐릭터·문장·이름은 베끼지 않는다.

## 1. 왜 첨부 교재는 사람이 만든 것으로 보이고, 우리 것은 생성물로 보이는가

| | 첨부 교재 | 우리 교재(현재) |
|---|---|---|
| **쪽 구도** | 쪽마다 구도가 다르다. 큰 것과 작은 것의 크기 차가 크다(글자 타일은 손바닥만 하고 단어 상자는 엄지만 하다). 왼쪽·오른쪽 쪽의 배경색과 리듬이 다르다 | 모든 쪽이 같은 세로 쌓기: 둥근 네모 카드를 같은 간격으로 쌓고, 안에 3×3 격자. 어느 쪽을 펴도 같은 모양 |
| **담는 틀** | 네모가 거의 없다. 유기적인 블롭(방울 모양)·구름·잎 위에 올린다. 그림 밑에는 테두리 대신 "그림자 웅덩이"(살구색 타원)를 깐다 | 모든 것이 테두리 있는 둥근 네모 안에 있다. 카드 안에 카드. 웹 앱 UI 느낌 |
| **겹침·삐져나옴** | 케이크가 글자 타일 줄 밖으로 삐져나오고, 아이 그림이 타일에 겹친다. 글자 타일은 ±3° 기울어 있다. 스토리 컷의 캐릭터가 컷 테두리를 넘는다 | 겹침 0. 모든 요소가 자기 칸 안에 정렬. 기울기 0 |
| **배경** | 한쪽 전체를 색면으로 칠하고, 잎·물감 튄 자국·정글 같은 큰 장식이 쪽 가장자리에서 잘려 들어온다 | 전부 크림색 바탕에 흰 카드. 장식 없음 |
| **색** | **유닛마다 한 가지 색**(살구/주황)만 쓰고 그 농담으로 쪽을 짠다. 강조는 한 색(분홍 모음) | 한 쪽에 빨강 A·파랑 B·초록 C·노랑 사이트워드·주황 유닛 배지 — 무지개. 클립아트 느낌의 원인 |
| **지시문 체계** | 작은 **캐릭터 아이콘 배지**(귀=듣기, i=말하기) + 영어 2~4단어("Listen and circle.") + 트랙 번호 배지. 끝 | 영어 지시문 + 회색 우리말 보조문이 오른쪽에 붙음 → "번역 자료" 인상. 글자가 작고 줄이 많음 |
| **예시 답** | 1번 문항은 **답을 미리 보여 준다**(분홍 점선 동그라미, 회색 따라쓰기 "date") → 우리말 설명이 필요 없다 | 예시 없음. 대신 우리말 설명으로 해결 |
| **쪽당 활동 수** | 1~2개. 요소가 크다. 여백이 넉넉 | 2~3개 + 9칸 격자 + 체크리스트. 빽빽 |
| **단어 그림** | 같은 크기·같은 틀(둥근 사각 + 색 바닥)에 넣는다. 배경 없음. 크기 통일 | 그림마다 배경 유무·크기·비율 제각각(우주인은 크고 화살은 가늘다). 그림마다 흰 네모 테두리 |
| **그림 화풍** | 색 3~4개, 단순한 도형, 음영 한 단계. 장면 그림도 "컷 안에서 필요한 것"만 그렸다 | 과한 렌더링: 반짝임·빛무리·꽃·해·풀이 모든 장면에. 디테일이 너무 많아 한눈에 생성 그림 |
| **스토리** | 컷 3~4개, 컷당 한 문장("I see two gates."), 목표 단어만 굵게. 장난 하나(똑같은 이름 Kate) | 컷마다 위에 노란 해설 띠 + 우리말 번역 + 말풍선 2개(/a/ /a/ apple!) + 아래 Find 띠. 글 장식이 그림보다 많다 |
| **복습 쪽** | 활동이 그림 안에 들어가 있다(바나나 나무에 단어, 정글 잎에 단어 사다리). 레이아웃 자체가 삽화 | 복습도 같은 카드 쌓기 |
| **쪽 장식** | 쪽번호는 모서리 동그라미 하나. QR은 유닛 첫 쪽에만, "Listen·Watch" 라벨 | 매 쪽 아래에 QR + "듣기" + "Student Book · Lesson 1" + 쪽번호 |
| **글꼴** | 제목은 둥글고 굵은 표시용 하나, 본문은 어린이용 산세리프(한 층 a·g), 쓰기 줄은 빨간 기준선 + 회색 점선 본보기 | Fredoka + Andika는 맞지만 제목이 작고 지시문·보조문이 섞여 위계가 없다 |

요약하면 "생성물 같다"는 인상은 그림 한 장 한 장보다 **① 같은 모양 반복 ② 모든 것을 네모에 가둠 ③ 색이 너무 많음 ④ 우리말 보조문 ⑤ 쪽마다 많은 글 장식** 다섯 가지에서 온다. 그림 자체는 "디테일 과잉·반짝임"이 주범이다.

## 2. 우리 교재에 적용할 규칙 (재설계 때 전부 지킨다)

### 쪽 구도
1. **쪽 유형마다 구도를 따로 설계**한다(글자 소개·따라 쓰기·단어 그림·활동·스토리·복습). 같은 카드 쌓기 템플릿 하나로 다 찍지 않는다.
2. 한 쪽에 활동 **최대 2개**. 요소는 크게, 여백은 넉넉히. 9칸 격자는 쓰지 않는다(최대 6칸, 2줄).
3. **크기 대비**를 만든다. 그 쪽의 주인공(글자·그림·타일)은 손바닥만큼, 나머지는 엄지만큼.
4. 펼침면의 왼쪽·오른쪽은 배경색이나 구도가 다르게.

### 담는 틀
5. 테두리 있는 네모 카드를 없앤다. 묶음은 **블롭·구름·색면·그림자 웅덩이**로 보여 준다. 선 테두리는 쓰기 칸과 답 칸에만.
6. 요소가 **서로 겹치고 틀 밖으로 삐져나오게** 한다. 글자 타일·단어 그림은 ±2~4° 기울이고 겹친다(쪽마다 다른 각도).
7. 쪽마다 **가장자리에서 잘려 들어오는 큰 장식**(잎·물감·꽃·구름) 하나.

### 색
8. **유닛 색 하나** + 그 농담(연한 바탕·진한 배지) + 강조 한 색(목표 글자·모음). 그 밖의 색은 그림 안에만.
9. 쪽 바탕은 흰색/아주 연한 유닛색. 크림색 바탕+흰 카드 조합은 버린다.

### 글과 지시
10. **학생 책·학생 화면에 우리말 0.** 지시는 ①아이콘 배지(듣기·말하기·쓰기·동그라미·잇기·찾기, 캐릭터가 들어간 작은 그림) ②영어 2~4단어 ③트랙 번호 배지로 끝낸다.
11. 모든 활동의 **1번은 답을 미리 보여 준다**(점선 동그라미·회색 본보기 글씨·연한 선). 우리말 설명을 이것으로 대체한다.
12. 지시문은 한 줄, 글꼴 크기는 본문보다 조금 크게, 굵게. 보조문·설명문 없음. 우리말은 선생님 자료와 화면의 "선생님 보기"에만.
13. 쪽 아래는 **쪽번호 동그라미 하나**. QR은 유닛 첫 쪽에 "Listen / Watch" 둘만.

### 그림
14. 단어 그림은 **같은 틀**: 배경 없는 물체 하나, 같은 크기, 둥근 사각 색 바닥 위. 흰 테두리 없음.
15. 장면 그림은 **컷 안에 필요한 것만**. 반짝임·빛무리·해·꽃밭·풀 디테일 금지. 색은 유닛 팔레트 안에서.
16. 캐릭터가 컷 테두리를 넘어오게 한다(한 컷에 하나).
17. 복습·게임 쪽은 **활동이 삽화 안에 들어가게**(나무에 단어 열매, 길 따라 단어, 잎 위 단어 사다리).
18. 화풍을 바꿔도(3D) 14~15는 그대로: 단순한 도형, 색 3~4개, 음영 한 단계, 무광.

### 스토리
19. 컷 3~4개, 컷당 **한 문장**(목표 단어 굵게). 말풍선은 컷당 최대 1개, 1~3단어. 해설 띠·번역·Find 띠는 컷 위에 올리지 않는다(찾기 단어는 쪽 아래 작은 줄 하나).
20. 유닛 스토리는 독립 에피소드. 글 없이 그림만으로 사건이 읽혀야 한다(설정집 0절 4번).

## 3. 코드로는 무엇이 바뀌는가 (재설계 작업 목록)
- `web/book/style.css`·`print.html`: 쪽 유형별 레이아웃 클래스 새로(`.pg-letters .pg-trace .pg-words .pg-act .pg-story .pg-review`), 블롭·그림자 웅덩이·가장자리 장식 SVG 묶음, 유닛색 변수 하나(`--u`)와 농담 변수, 기울기·겹침용 유틸.
- `pages.js`: 쪽 유형마다 구도를 가진 렌더러(격자 공통 함수 폐기), 1번 문항 예시 답 표시, 우리말 보조문을 학생 층에서 제거(선생님 층에서만 켬).
- 지시 아이콘 세트(SVG 6종, 캐릭터 포함)와 트랙 번호 배지.
- 공방: 단어 그림 프롬프트를 "배경 없는 물체 하나·같은 크기" 틀로, 장면 프롬프트에 디테일 금지 조항, 3D 화풍 스타일 문장 교체, 캐릭터 기준 그림 재생성.
- PDF: A4 재단 여백(3mm) + 쪽마다 다른 배경 색면이 가장자리까지 가도록 bleed.
- 검사: 자동 QA에 "쪽당 활동 수 ≤2", "학생 층에 한글 0", "지시문 한 줄" 규칙 추가.

## 4. 진행 순서
1. 3D 화풍 시안(캐릭터 4명 기준 그림 + 장면 1장 + 단어 3장) 승인.
2. **1권 1유닛 파일럿**: 새 스토리 대본 + 위 규칙으로 쪽 유형 6가지를 전부 한 번씩 만든 PDF(약 8쪽)와 화면. 첨부 교재 옆에 놓고 비교.
3. 승인 후 1권 전체 → 2~4권.
